# Consumo de API usando Javascript Puro

| #  | Desafio | API | Projeto |
| --- | ------ | ---------- | ---------- |
| 1. | Consumir uma API de CEP e preencher um formulário como as informações do endereço. | [ViaCEP][viacep-api] | [Cadastro][viacep-projeto] |
| 2. | Consumir uma API de imagens e criar uma pesquisa retornando uma galeria com as imagens. |[Pixabay][pixabay-api] |[Pesquisa de imagens][pixabay-projeto] |
| 3. | Consumir uma API de imagens de cachorros por raça. | [Dog CEO][dogapi-api] | [Galeria de cachorros][dogapi-projeto] |
| 4. | Consumir uma API de imagens de gatos e exibir uma galeria. | [TheCatAPI][catapi-api] | [Galeria de gatos][catapi-projeto] |
| 5. | Gerar perfis aleatórios de usuários. | [Random User][userapi-api] | [Gerador de usuários][userapi-projeto] |
| 6. | Buscar informações de países, como bandeira e capital. | [REST Countries][countryapi-api] | [Informações de países][countryapi-projeto] |
| 7. | Consultar a previsão do tempo por cidade. | [WeatherAPI][weatherapi-api] | [Previsão do tempo][weatherapi-projeto] |
| 8. | Gerar avatares com diferentes estilos. | [DiceBear][dicebear-api] | [Gerador de avatares][dicebear-projeto] |
| 9. | Buscar e traduzir citações estoicas para português. | [Stoic Quotes][quotes-api] e [MyMemory][translation-api] | [Tradutor de citações][quotes-projeto] |
| 10. | Buscar e comparar super-heróis. | [SuperHeroAPI][heroi-api] | [Herói vs. Herói][heroi-projeto] |
